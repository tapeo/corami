# Contributing to Corami

Thank you for your interest in Corami.

## Before you start

- For anything larger than a small fix, open an issue first, so we can agree on the change before you write it.
- The project rules are in [AGENTS.md](AGENTS.md); the architecture is in [docs/architecture.md](docs/architecture.md) and the development environment in [docs/development.md](docs/development.md).
- Run `bun run verify` before you open the pull request.

## Contributor license agreement

Every pull request must accept the [Corami CLA](CLA.md). You keep the copyright of your work; the CLA lets the maintainer distribute it under the license of the project, today the [Functional Source License](LICENSE), and under future licenses.

The pull request template contains the statement that signs it. Leave it in the description: a check fails until it is there.
